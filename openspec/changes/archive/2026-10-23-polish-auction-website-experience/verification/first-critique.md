# First composition critique

Inspected first-home.png, first-lot.png and first-mobile.png before extending the
patterns to account/admin. Home now anchors the selected stored collection and
keeps featured events ahead of independent suggestions. The object/detail plates
share materials and silhouettes. At 375 px the image leads, controls flow and the
language/menu affordances stay compact. No fabricated counts or sample auctions.

Lot inspection is visually dominant; the functional column holds exact price,
condition and all fulfillment terms before submission. No sticky overlay conceals
the terms. Long bid histories make this column tall, so it intentionally stays in
normal document flow at all sizes. Follow-up: emphasize current price, remove the
remaining auction capability paragraph, and replace the public-fallback reason
with plain discovery language before extending this vocabulary to utility pages.

Fixture caveat: the original analytics rehearsal deliberately marked some stock
lots/events non-demo. Their raw authored prose stays untouched by the bounded
adapter, as specified; replacing their text just for a screenshot would conceal
that boundary. Dedicated adapter tests cover genuinely provenance-marked stock
and historical snapshots. Artwork paths upgrade regardless of provenance.

Second pass: removed remaining mounted capability prose from account/catalog and
auction dictionaries, simplified recommendation recovery/reasons, and retained
operator analytics definitions. Shared list rows now give catalog images a stable
thumbnail role. Checkout uses three labeled form groups and confirmed review/
receipt steps. Private sections use immediate unmounts; only public gallery/menu
portals can retain an exit transition. This keeps visual feedback subordinate to
identity cleanup and server-confirmed outcomes.
