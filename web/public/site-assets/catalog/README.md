# Catalog illustrations

All 39 SVG files in this directory were authored for AuctionLab by project code in this change: 18 object illustrations, 18 detail studies, and three collection covers. No photographs, third-party marks, remote assets, or historical authentication evidence were used. They are demonstration illustrations, not representations of actual objects offered for sale.

Source: project-authored geometric SVG paths and system-font text; rights: CC0-1.0 (dedicated to the public domain). All five categories are illustrative. Titles, conditions, specifications and provenance stories in the seed are explicitly fictional demo content. The runtime fallback is the existing `/site-assets/image-unavailable.svg`.
